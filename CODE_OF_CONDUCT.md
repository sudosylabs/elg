# Code of conduct

Everyone contributing to this project deserves respectful treatment, regardless of background, identity, experience, or disability.

Be considerate, give constructive feedback about the work, and respect other people's privacy. Harassment, discriminatory language, threats, sexualized content, personal attacks, and publishing private information are unacceptable in issues, pull requests, discussions, and other project spaces.

Maintainers may edit or remove inappropriate contributions, lock discussions, or restrict participation. Enforcement should be proportionate and consistent, and should explain the relevant behavior without revealing private reports.

For public incidents, flag the relevant contribution to maintainers using GitHub's reporting controls where available. For threats, harassment, or private information, use [GitHub's abuse reporting process](https://docs.github.com/en/site-policy/acceptable-use-policies/github-abuse-and-spam) rather than posting sensitive details publicly. Maintainers must not retaliate against someone for reporting a concern in good faith.
